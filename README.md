# Hi, I'm Manikanta Chintapalli 👋

### Embedded Systems Enthusiast | Low-Level Developer

I am an Embedded Developer driven by a deep curiosity for how computing systems work at the register and protocol levels. I focus on writing lean software that respects hardware constraints, bridging the gap between raw hardware signals and clean firmware architecture. 

This GitHub profile serves as my open projects where I share my learning journey, core data structure libraries, and hardware experimentation modules.

---

### 🚀 Technical Core & Focus Areas

*   **Bare-Metal Programming:** Writing foundational code using **C** and **Assembly** (8051/ARM), optimizing logic for resource-constrained architectures.
*   **Silicon-Level Exploration:** Exploring hardware architectures through **STM32**, and **ARM Cortex** microcontrollers to understand register-level configurations.
*   **Protocol Implementations:** Working with standard communication interfaces including **UART, I2C, SPI**, and exploring network/wireless connectivity layers like **MQTT** and **BLE**.
*   **Hardware-Level Debugging:** Utilizing **oscilloscopes** and **logic analyzers** to analyze waveforms, decode serial communication, and translate raw signals into functioning software loops.
*   **Firmware Craftsmanship:** Structuring code using modular practices and creating foundational data structure building blocks to write maintainable firmware.
